# OS Group 4 — FLASH GAME

## Project Overview

FLASH GAME is a browser-based game collection developed as part of our university Operating Systems and Networking project. The project aims to provide a simple way to access classic-style games through a web browser while demonstrating concepts related to Linux system administration, networking, and web deployment.

## Objectives

- Host a browser-accessible collection of games.
- Use GitHub for source code management and team collaboration.
- Deploy the website using a cloud hosting platform.
- Demonstrate Linux administration concepts, including users, groups, file permissions, and process management.
- Document networking concepts, connectivity tests, and deployment results.

## Technologies

- **GitHub** — Source code management and collaboration
- **HTML, CSS, and JavaScript** — Website interface and browser-based functionality
- **Render** — Planned cloud hosting platform
- **Linux and Bash** — System administration scripts and demonstrations
